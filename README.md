# Regex-детектив

Консольная игра, в которой нужно раскрыть дело с помощью регулярных выражений.

## Правила

Из лаборатории пропали секретные чертежи. Игра состоит из 4 раундов:
по две главы, в каждой по два раунда.

В каждом раунде игрок получает задание и примеры, а затем вводит регулярное
выражение. Программа проверяет его на примерах из задания и на скрытых примерах.

- Если шаблон верный, игрок получает улику и переходит к следующему раунду.
- Если шаблон работает неправильно, игра показывает пример, на котором он ошибся.
- Если в шаблоне синтаксическая ошибка, игра сообщает об этом и не прерывается.
- Чтобы получить подсказку, введите `?`.

После всех раундов игра показывает собранные улики и называет вора.

## Запуск

```
python main.py
```

Проверки глав:

```
python test_passes.py
python test_archive.py
```

## Как устроен проект

- `game_round.py` - общий класс `Round`. У каждого раунда есть метод
  `check(pattern)`, который возвращает пару (успех, сообщение).
- `main.py` - общий файл запуска и игровой цикл. Каждая глава подключается
  к игре в своей строке списка раундов.
- `passes.py` - глава «Бюро пропусков» (`re.fullmatch`)
- `archive.py` - глава «Архив переписки» (`re.finditer`)
